## Contoh 2 - Wireframe Portal Akademik

Isi: header, navigasi, sidebar menu, hero dashboard, informasi akademik, layanan mahasiswa, dan footer.

```
desain-web/
└── pertemuan-05/
    └── contoh2/
```

## Keterangan

- index.html : halaman utama
- css/style.css : file styling
- images/ : tempat gambar
- dokumentasi/ : tempat screenshot / dokumentasi

## Cara Menjalankan

Buka index.html di browser, atau gunakan Live Server di VS Code.
